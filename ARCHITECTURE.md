# FinSage Architecture Overview

FinSage is built using a modern MERN stack with additional integrations for a powerful, AI-driven financial council.

## Frontend
- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS, Shadcn UI
- **Animations**: Framer Motion, Remotion for dynamic video synthesis

## Backend
- **Framework**: Node.js + Express
- **Database**: MongoDB (Mongoose ORM)
- **AI Core**: Multi-agent architecture (Google Gemini / Groq) for Budget, Savings, Debt, and Investment agents.

## Integrations
- **Authentication**: Firebase Auth
- **Banking**: Plaid API for transaction syncing
- **Notifications**: Twilio / WhatsApp integration for alerts
